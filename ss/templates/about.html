About this build

SteamScope is a Year 12 IT Major Project prototype. It compares two public Steam profiles' hours played, owned games, shared games, and achievement completion on one dashboard.

In scope

  • Profile search by SteamID64 or profile URL
  • Display of public user information
  • Comparison of total hours, owned games and shared games
  • Comparison of achievement completion for shared games
  • Charts of the above statistics

Out of scope

Private Steam data, purchasing, messaging, and account management. SteamScope never collects passwords — authentication stays with Steam's own systems.

How it's built

Flask (Python) backend, SQLite for caching profile/game data, and the Steam Web API (GetPlayerSummaries, GetOwnedGames, GetPlayerAchievements) for live data. Achievement comparison is scoped to each pair's top shared games by playtime to keep a comparison fast.
