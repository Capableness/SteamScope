Questions

Why was a profile rejected as private?

Steam only shares the game list when Game details is Public. On Steam go to Edit Profile, then Privacy Settings, and change it. It can take a minute to apply.

Why are achievements only checked for some games?

Steam needs one request for every game, so only the 12 most played shared games are checked. This keeps searches quick.

What does this site save?

Public profile names, game lists, hours and achievement counts are saved for a few hours so repeat searches are fast. The lists above show these saved public names. Signing in only stores your name and Steam ID in a cookie. Your password stays with Steam.
